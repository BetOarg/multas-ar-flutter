Política de Privacidad

Multas Argentina Pro

Última actualización: octubre de 2026

Compromiso: las fotos de actas, patentes, nombres, DNI, domicilios, texto OCR, casos, escritos y configuración se procesan y almacenan localmente. La app no incorpora una API de OCR/IA en la nube, no sincroniza datos y no debe transmitir esos datos a servidores.

1. Responsable y contacto

Multas Argentina Pro es desarrollada por BetOarg, Buenos Aires, Argentina. Contacto: privacidad@multasargentina.app.

2. Datos procesados

La aplicación puede procesar localmente:

  • Fotos o imágenes de actas seleccionadas por el usuario.
  • Texto extraído mediante OCR, incluidos patente, fecha, número de acta y otros campos.
  • Casos, plazos, alertas, escritos generados y datos de configuración profesional.
  • Preferencias y datos necesarios para las funciones locales.

Estos datos se almacenan en el dispositivo. No se envían automáticamente a servidores propios ni de terceros. La base de datos utiliza SQLite/Drift; no afirmamos que toda la base esté cifrada a nivel de archivo. Los datos sensibles de configuración guardados mediante flutter_secure_storage usan los mecanismos de protección disponibles en el sistema operativo.

3. OCR y análisis

El OCR está diseñado para ejecutarse en el dispositivo: PaddleOCR/ONNX en Android, Apple Vision en iOS y ML Kit como alternativa local. La disponibilidad y precisión de cada motor dependen de que la integración nativa y los modelos se hayan compilado y validado correctamente. No se utiliza una API remota de OCR ni de análisis con IA.

4. Conexiones externas y acciones del usuario

La aplicación no debe realizar llamadas de red automáticas ni enviar datos de actas, patentes, identificadores o perfiles. La normativa incluida se carga desde archivos locales de la aplicación; no se actualiza automáticamente por Internet.

Si el usuario decide abrir un portal oficial en el navegador, el navegador y el sitio elegido quedan fuera del control de la aplicación y se aplican sus propias políticas. La app no debe adjuntar automáticamente la patente ni otros datos del caso a la dirección del portal. Del mismo modo, si el usuario exporta o comparte un documento mediante las funciones del sistema operativo, el destino elegido por el usuario puede recibir ese documento.

5. Permisos

  • Cámara y galería: para capturar o seleccionar imágenes que se procesan localmente.
  • Notificaciones: para recordatorios locales de vencimientos.
  • Almacenamiento/archivos: para importar o exportar documentos cuando el usuario lo solicita.

6. Publicidad, seguimiento y cuentas

No se incorporan anuncios, analíticas, seguimiento publicitario, sincronización en la nube ni cuentas remotas en esta versión. No vendemos ni compartimos datos con anunciantes.

7. Eliminación

Los datos locales pueden eliminarse desde las funciones de gestión de datos disponibles en la app o desinstalando la aplicación. Antes de publicar, debe comprobarse que la opción de eliminación anunciada en la interfaz exista y elimine realmente la base de datos, archivos e imágenes asociados.

8. Menores

La aplicación está orientada a personas adultas que gestionan infracciones de tránsito.

9. Cambios y contacto

Los cambios materiales en esta política se reflejarán en esta página. Para consultas de privacidad o para ejercer derechos de acceso, rectificación, actualización o supresión, escribí a privacidad@multasargentina.app.

10. Marco legal

Esta política toma como referencia la Ley 25.326 de Protección de los Datos Personales de Argentina. La aplicación debe revisarse y validarse jurídicamente antes de su publicación.

Referencia oficial: Agencia de Acceso a la Información Pública (AAIP).
